# 🧠 Memory Moves
A simple and fun Memory Match Game built just to tackle Doomscrolling.
In Memory Moves the player has to match all of the 6 pairs and try to complete the game in as few moves as possible!

# 💻 Built With :
- HTML5
- CSS3
- JavaScript
- Local Storage

# 🚀 Getting Started

You don't need to install any additional software or dependencies to play the game.

1. Clone the repository

## git clone YOUR_REPOSITORY_URL

2. Open the project folder

## cd Memory-Moves

3. Run the game

Open index.html in your web browser.

That's it! You're ready to play.

Alternatively, you can use the VS Code Live Server extension to run the project locally.

# 🎮 How to play 
- Open the game in your browser.
- You'll see a board containing shuffled , hidden cards .
-  Click on any two cards to reveal them and remember the symbols and match them with the other cards .
-  Continue until all six pairs are matched.
-  Try to beat your previous best score!
